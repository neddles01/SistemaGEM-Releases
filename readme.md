# neddlesSY — releases

A edição Normal está na versão **1.8.18**, com três cliques de F2 no ataque duplo.

[Patchnotes e instaladores da 1.8.18](https://github.com/neddles01/SistemaGEM-Releases/releases/tag/1.8.18)

A sequência de F2 usa o mesmo ponto, com 250 ms entre o início dos cliques
e o botão direito pressionado por 120–160 ms em cada tentativa. F1 retorna
no próximo clique disponível. O próximo ciclo de F2 aguarda pelo menos 8,5 s
desde o último clique enviado e respeita recargas configuradas maiores.

Feche o macro e abra pelo atalho da edição Normal para receber a atualização.
Para atualização manual, execute `Setup-neddlesSY-v1.8.18.exe` como administrador
sobre a instalação existente. `Setup-SistemaGEM-v1.8.18.exe` é o arquivo idêntico
usado por atualizadores antigos. Os dois hashes estão em `SHA256SUMS.txt`.

A edição Normal usa texturas normais dos monstros e roda na CPU. A edição Low
Engine é distribuída em seu próprio canal.
