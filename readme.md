# neddlesSY — releases

Versão atual: **1.8.9**.

[Notas e instaladores da 1.8.9](https://github.com/neddles01/SistemaGEM-Releases/releases/tag/1.8.9).

Use `Setup-neddlesSY-v1.8.9.exe` para instalar ou atualizar sobre a versão
existente. O asset `Setup-SistemaGEM-v1.8.9.exe` é uma cópia idêntica, mantida
para o auto-update de clientes antigos. Os hashes estão em `SHA256SUMS.txt`.
Não precisa desinstalar para atualizar.

Patch de buffs: antecipação visual só na bolha do Mago (~8% de margem).
Demais buffs seguem timer completo por padrão; opção manual de 10 s mantida.
Inclui a correção de abertura sem WMIC da 1.8.8 e mantém autenticação/HWID.

Este repositório contém somente a distribuição e os metadados de atualização;
não recebe configurações, calibrações, logs ou credenciais de usuários.

Histórico: distribuição iniciada na versão 1.5.3.
