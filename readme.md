# neddlesSY — releases

Versão atual: **1.8.8**.

[Notas e instaladores da 1.8.8](https://github.com/neddles01/SistemaGEM-Releases/releases/tag/1.8.8).

Use `Setup-neddlesSY-v1.8.8.exe` para instalar ou atualizar sobre a versão
existente. O asset `Setup-SistemaGEM-v1.8.8.exe` é uma cópia idêntica, mantida
para o auto-update de clientes antigos. Os hashes estão em `SHA256SUMS.txt`.
Não precisa desinstalar para atualizar.

Patch de abertura: removida a consulta de CPU que chamava WMIC.exe e podia
impedir a inicialização. Chave da máquina, autenticação e rotinas preservadas.

Este repositório contém somente a distribuição e os metadados de atualização;
não recebe configurações, calibrações, logs ou credenciais de usuários.

Histórico: distribuição iniciada na versão 1.5.3.
